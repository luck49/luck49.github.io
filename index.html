D1 · 9.30 周三

北京 → 承德 ｜ 避暑山庄·小布达拉宫

🚗 230km / 3h🛏 宿承德
06:30出门早餐、装车
07:00准时出发：京承高速 G45 北上，节前最后工作日早高峰出城方向基本顺畅（中途太子服务区休息一次）
10:00抵承德市区，酒店放行李（建议住避暑山庄丽正门附近，步行可达）
10:30午餐：老三羊汤（羊汤+烧饼，人均25）
11:30避暑山庄（丽正门进）：宫殿区（澹泊敬诚殿，金丝楠木大殿）→ 博物馆 → 湖区（环碧、烟雨楼，可乘游船约40/人）→ 平原区万树园 → 试马埭。出园前在南山积雪亭俯瞰外八庙全景。门票130，60岁以上免票；务必提前在公众号「避暑山庄及周围寺庙」约好时段票，刷身份证入园
16:00（可选）加游普陀宗乘之庙（小布达拉宫，门票80，1.5h）——就是在南山积雪亭看到的那片红台白台
18:00晚餐：大清花饺子 / 御土荷叶鸡
20:00（可选）《鼎盛王朝·康熙大典》实景演出（约1.5h，198–280元，提前一天公众号购票）
今日是高速免费前一天，过路费约 100 元。
D2 · 10.1 周四

承德 → 玉龙沙湖 → 赤峰 ｜ 白沙漠+碧湖

🚗 ~430km / 5h🛏 宿赤峰
07:00出发（今天全中国出京大堵车，而你已经在承德，赢麻了）。导航「玉龙沙湖景区」（翁牛特旗乌丹镇）：大广高速→围场北方向→省道，约320km/4h，中途服务区休息一次
11:30抵玉龙沙湖（大门票80），景区内免费停车场。午餐景区内简餐（泡面/盒饭水平，别期待太高）
12:15游玩：走境漠线——白沙漠+碧湖（石英白沙，出片不输鸣沙山）、乘沙漠越野车冲沙（约150/车次，初/中/高三级赛道，最值得花钱的项目）、骑骆驼（约50–80）、沙地摩托；体力一般可走境水线看红山羽神岩画与湿地。这里是1971年「中华第一龙」C形碧玉龙的出土地，在玉龙广场打卡
15:00出发 → 赤峰市区（约90km/1.5h）
16:30抵赤峰入住（红山区万达/维多利一带吃饭方便）
18:00晚餐：对夹（赤峰招牌，酥皮夹熏肉，城南对夹老店）+ 蒙餐（罕山手把肉）
今晚把明天热水塘的温泉酒店订好（推荐见 D3）。
D3 · 10.2 周五

赤峰 → 辽代博物馆 → 巴林右旗 → 热水塘 ｜ 契丹辽文化+83℃温泉

🚗 ~350km / 4h🛏 宿热水塘（温泉）
09:00辽代历史文化博物馆（红山区钢铁西街，体育场西侧）：免费，带身份证现场领票/预约。全国唯一全面展示宋辽金历史的专题博物馆，镇馆看契丹金银器、辽瓷、陈国公主墓文物复刻。10:00 有免费讲解，跟住讲解员效率翻倍。注意：赤峰博物馆（松山馆区）因消防维修闭馆中，别跑错
10:45出发 → 巴林右旗大板镇（G16 丹锡高速，180km/2h）
13:00大板午餐：巴林手把肉/涮羊肉（人均60）
14:00巴林石博物馆（免费，索博日嘎街）：中国四大印石之一的鸡血石/冻石精品，地下一层可看加工车间；步行可达康熙行宫民俗博物馆（国家三级馆，民族服饰+宗教法器）
15:45出发 → 热水塘镇（约150km/2h，G16 转经棚方向）
18:00抵热水塘，入住温泉酒店，泡 83℃ 天然矿物温泉（含40多种微量元素）
19:00晚餐：金泉美食城 / 街边烧烤+烤羊排
🏨 住宿推荐：蓝天温泉大酒店（4.2分，标间双浴缸温泉入户，送泡澡袋，约300–400）；山水温泉宾馆（经济款200上下，院里有充电桩，电车友好）；天牧温泉小镇（欧式独栋汤屋，情侣/家庭升级款500+）
可选支线（默认不安排）：若极度痴迷辽文化，可大板→索博日嘎镇（115km）看庆州释迦佛舍利白塔，但要多开230km山路，D3 会爆，慎选。
D4 · 10.3 周六

热阿线 → 阿斯哈图石林 → 达达线 → 达里湖 → 经棚 ｜ 全天风景驾驶日

🚗 ~260km / 4.5h🛏 宿经棚
08:00出发上热阿线（热水塘→黄岗梁→石林，约88km）：前段河谷白桦林，中段翻大兴安岭最高峰黄岗梁（海拔2029m，免费，可短暂停留观景台），后段平缓草原。走走停停拍照约2.5h；途中很黑村（网红地名）买现炒瓜子
10:30阿斯哈图石林（5A，门票120+观光车40必坐）：花岗岩石林地貌世界独一份，乘观光车串「草原石林区→鲲鹏区→七剑山/城堡区」，栈道一圈约2.5h。周六人多，8:30 开园越早进越好——所以 08:00 必须从热水塘出门
13:15景区门口农家院午餐（炖菜/手把肉，人均50）
14:00上达达线反向（石林→达里湖方向，约80km/2h风景路）：白音敖包沙地云杉林停留30min（世界唯一沙地云杉原始林，门票约30，可选）
16:00达里诺尔湖（门票约80–90）：内蒙第三大湖、碱性半咸水湖，10月初正值候鸟南迁，带望远镜看天鹅/大雁；顺路尝华子鱼（瓦氏雅罗鱼，干炸最香）
17:45出发 → 经棚镇（约90km/1.2h）
19:00抵经棚入住（克什克腾旗政府驻地，住宿餐饮最全；今晚给车加满油，明天草原段加油站稀疏）
全天草原腹地手机常无信号，今晚把经棚→大青山→乌兰布统的离线地图更新好。
D5 · 10.4 周日

经棚 → 大青山 → 乌兰布统 ｜ 岩臼奇观+草原日落

🚗 ~170km / 3h+景区🛏 宿乌兰布统
08:00早餐（经棚对夹/奶茶）后出发
08:30大青山景区（克什克腾世界地质公园青山园区，经棚东南约25km，经乌线顺路）：门票+索道套票约120–160（索道必坐，1230米内蒙古第一高山索道，单程18分钟；下索道后还需20分钟摆渡车+一段台阶栈道）。山顶看世界最大岩臼群「九缸十八锅」——上千个第四纪冰川凿出的圆坑，大如水缸，如同外星密码；另有巨鹰石、乌龟石等象形石阵+高山草甸。开放8:30–18:30
12:00返回经棚方向午餐（或直接路上小饭馆）
13:00出发 → 乌兰布统（约110km/2.5h，经乌线本身就是风景路，牛羊成群随时停）
15:30抵乌兰布统乡/红山军马场，买大门票120（首次验票录人脸，3天内不限次进出，收好票根）；国庆房价约500–800/晚，比承德贵，忍了
16:00顺序打卡：影视基地（还珠格格/康熙王朝取景地，木栈道登顶俯瞰全景）→ 将军泡子（湖泊倒影+沙地疏林，日落前光线最美）
18:00日落（10月初坝上日落约17:30–17:50）后回镇晚餐：手把肉+草原奶茶（人均70）
觉得节奏太赶可砍大青山：08:30 直接出发去乌兰布统，中午到，多出一下午逛盘龙峡谷。
D6 · 10.5 周一

公主湖晨雾 → 蛤蟆坝/桦木沟 → 古北水镇 ｜ 强度日，按钟点走

🚗 ~400km / 5h🛏 宿古北水镇/密云
06:30出门（晨雾8点前散，这是全程最值得早起的一次）。公主湖在主景区外、需再次验票（120大票3天内有效）：白桦+晨雾+湖面倒影，蓝齐儿格格传说地。日出前后气温接近0℃，羽绒服穿足
08:00回镇早餐（热奶茶+果子）
09:00桦木沟蛤蟆坝景区（门票30，距红山军马场20余km，最后几公里乡间土路，轿车慢开可过）：万顷桦林+金蟾湖+摄影基地，沟谷里牛羊、茅屋、栅栏随手拍都是屏保；体力好可去盘龙峡谷（同样主景区外，需验票）
11:45回镇午餐，13:00 准时出发（不堵车铁律：今天要跨过整个承德）
13:00路线：乌兰布统→四御公路→围场→G45 大广→承德绕城→京承高速→古北水镇，约400km/5h 含一次服务区休息。18:00 前后过承德，避开返京同向车流高峰尾部
18:30抵古北水镇（密云古北口；住镇内车停P1/P2停车场，住密云县城更省，房价差近一半）
19:00夜游水镇（国庆运营至22:30）：司马台长城提灯夜爬、日月岛广场无人机秀/孔明灯、山顶教堂俯瞰全镇灯火、音乐喷泉；逛小吃街（密云烧肉、古北烤梨）。夜游无需再买大门票即可逛部分街区，登长城单独购票（联票约140，以景区小程序当日价为准）
周一各博物馆闭馆，但今天只玩水镇，无影响。
D7 · 10.6 周二

古北水镇 → 北京 ｜ 晨雾补拍，午前到家

🚗 140km / 2h🏠 到家
07:30早起在镇里拍晨雾（水镇清晨没人，是最出片时段）；镇内早餐
09:00白天补拍：永顺染坊（蓝印花布晾晒场）、英华书院、镖局展馆——白天场3个点位逛完就撤（重头戏昨晚已看）
10:00出发：京承高速→北京，约140km/2h
12:00到家。全国返程最高峰是今天下午13:00后和明天10.7，你在午饭后就躺沙发了 😎
回程正好错峰：出京方向的拥堵与你无关，返京高峰又还没开始。
